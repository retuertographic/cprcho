# El Capricho de Costa del Silencio — Carta y Tienda Gourmet

Carta digital multilingüe (ES, EN, FR, DE, NL, RU, IT, PT) de El Capricho de Costa del Silencio.

- `index.html` — página completa (estilos, logo y carta integrados).
- `menu-data.js` — opcional: define `window.MENU_DATA` para sustituir la carta.
- `.github/workflows/deploy.yml` — despliegue automático a GitHub Pages.
